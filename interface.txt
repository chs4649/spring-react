========================================================================

signIn(ログイン)

- request
{
    *email: String
    *password: String
}

- response

成功

Http Status - 200 (OK)
{
    code: "SU", 
    message: "Success.",
    token: "jwt...",
    expireDate: 123456789
}

失敗

- 必須情報未入力

- ログイン失敗
Http Status - 401 (Unauthorized)
{
    code: "SF",
    message: "Sign In Failed."
}

- データベースエラー
Http Status - 500 (Internal Sever Error)
{
    code: "DE",
    message: "Database Error."
}

{

    password: String,
    nickname: String,

    address: String,
    addressDetail: String
}

- response

成功

Http Status - 200 (OK)
{
    code: "SU", 
    message: "Success."
}

失敗

- 必須情報未入力 / メールアドレス不一致 / パスワード8文字未満 / 電話番号不一致

- メールアドレスの重複
Http Status - 400 (Bad request)
{
    code: "EE",
    message: "Existed Email."
}

- データベースエラー
Http Status - 500 (Internal Sever Error)
{
    code: "DE",
    message: "Database Error."
}
